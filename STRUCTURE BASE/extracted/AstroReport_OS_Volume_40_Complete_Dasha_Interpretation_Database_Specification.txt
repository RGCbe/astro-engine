Database Schema
Each timing record stores planetary ruler, timing hierarchy, activation rules, supported life domains,
narrative templates, validation metadata and multilingual labels.
Recommended Fields
Dasha ID, parent period, planet, duration, themes, evidence rules, transition rules, event links,
paragraph IDs, confidence scores, graph edges and version history.
Developer Specification
Expose immutable IDs, indexed retrieval, timeline APIs, semantic metadata and audit-friendly
version control.
