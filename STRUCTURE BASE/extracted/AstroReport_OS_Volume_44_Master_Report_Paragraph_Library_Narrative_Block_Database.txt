Purpose
This manual defines the reusable paragraph repository used by AstroReport OS. Instead of storing
complete reports, the system stores modular narrative blocks that are dynamically assembled into
personalized timeline reports.

Library Design
Each paragraph should be independent, tagged by topic, life domain, timeline stage, tone, reading
level and supporting astrological evidence.
Assembly Rules
The report engine selects compatible blocks, removes duplication, maintains chronology, inserts
transitions and adapts wording to the reader profile.
Developer Specification
Maintain immutable paragraph IDs, embeddings for semantic search, multilingual variants, version
history, approval status and graph links.
