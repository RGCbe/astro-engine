Prompt Design Principles
Keep prompts modular. Separate retrieval, reasoning, narrative generation and validation into
independent stages. Pass structured data instead of raw text whenever possible.
Context Management
Include only relevant chart facts, timeline events and knowledge objects. Avoid unnecessary
context to improve consistency and efficiency.
Quality Controls
Use automated validation after generation to check completeness, consistency, unsupported
claims, formatting and readability before final rendering.
Developer Specification
Maintain prompt templates, version numbers, model compatibility notes, evaluation datasets,
fallback strategies and orchestration workflows.
