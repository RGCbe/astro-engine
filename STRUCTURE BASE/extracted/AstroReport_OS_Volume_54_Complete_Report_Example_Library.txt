Example Structure
Every example should include chart summary, evidence trace, timeline chapters, life events,
guidance, Q&A; section, confidence notes and reusable paragraph references.
Library Strategy
Maintain curated reference reports representing diverse chart patterns. Use them as benchmark
outputs for model evaluation and future improvements.
Developer Specification
Store report IDs, chart metadata, anonymized inputs, expected outputs, quality scores, retrieval
tags, embeddings, version history and approval status.
