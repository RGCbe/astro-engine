Purpose
This specification defines how AstroReport OS adapts a report to the reader while preserving the
same astrological evidence. Personalization changes the presentation, depth and language, not the
underlying interpretation.

Adaptation Rules
Personalization must never change the astrological conclusion. It only changes wording, examples,
narrative depth, reading level, illustrations and chapter emphasis according to the reader profile.
Quality Checks
Verify consistent terminology, reading level, timeline continuity, personalization settings, and
evidence integrity before rendering the final report.
