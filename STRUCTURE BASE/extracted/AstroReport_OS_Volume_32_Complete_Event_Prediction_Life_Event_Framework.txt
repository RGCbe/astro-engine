Supported Event Categories
Education, career, business, finances, marriage, relationships, children, property, travel, relocation,

Prediction Workflow
Identify candidate events, collect supporting evidence, determine timing windows, assign
confidence, merge related events, generate a chronological narrative and validate consistency
before report publication.
Developer Specification
Each event object stores event ID, domain, supporting evidence, timing range, confidence score,
severity/importance, related questions, narrative template and cross references.
Ethical Presentation
Present events as interpretations derived from chart patterns. Clearly distinguish confidence levels
and avoid portraying uncertain outcomes as certainties.
