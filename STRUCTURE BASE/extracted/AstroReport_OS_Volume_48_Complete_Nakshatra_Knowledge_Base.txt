Knowledge Record Template
Each record should contain: Knowledge ID, Nakshatra, Pada, ruling planet, symbolism, personality,
emotions, life domains, timeline effects, Dasha interaction, child explanation, professional
explanation, narrative blocks, confidence score and cross references.
Population Strategy
Create atomic records for each Nakshatra concept so the report engine can assemble personalized
interpretations instead of relying on static text.
Developer Specification
Support multilingual content, semantic search, embeddings, graph relationships, immutable IDs,
version history and API-ready retrieval.
